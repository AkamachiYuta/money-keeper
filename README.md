## お金を前に差し出すのをやめよう

企業によって過剰な消費を促されることの多い現代社会にうんざりしていませんか？

本当に便利な世の中になったのでしょうか？

ポイントは本当にお得なんでしょうか？

QR コード決済は本当に便利なんでしょうか？

「オススメの情報」とやらは本当に必要なんでしょうか？

企業による過激なユーザーの囲い込み合戦に巻き込まれ、数多の情報や広告に踊らされるのにうんざりした私は、まずは真に必要な情報だけを表示するための家計簿を欲していました

## 本当の使いやすさを目指して

各銀行口座やキャッシュレス決済事業者などは、API をクローズドにし、営利目的のために独占していますので、自動取得をすることは難しいです。しかし、手動で入力する前提であれば、自作することは可能だと考えました

また、MoneyF...のCSVエクスポート機能などを利用してデータを取り込むことで、手動管理の手間を軽減することも可能です。

お金の情報管理を自由に、オープンにすることが、MoneyKeeper の最終的な目標です。自分たちのお金は自分たちのものです。その情報をどのように扱うべきかは、自分たちで決定する権利があるはずです

もしこの考えに共感いただけましたら、ぜひあなたのアイデアをIssueやディスカッションでお聞かせください。MoneyKeeper が、あなたのお財布の番人 (Keeper) となれれば幸いです

## ステータス

このアプリは現在アルファ版として、主要機能の開発を進めています。基本的な家計簿としての利用は可能ですが、いくつかの機能は未実装、または動作が不安定な場合があります。

[デモアプリ (prime ブランチが自動反映)](https://akamachiyuta.github.io/money-keeper/)
詳細な開発状況や実装予定の機能については、[CONTRIBUTING.md](README/CONTRIBUTING.md)の機能リストをご確認ください。

## 開発について

このアプリは現在、主に1名の開発者によって愛を込めて開発が進められています。そのため、大規模な更新や機能追加にはお時間をいただく場合がございます。
開発にご協力いただける方がいらっしゃいましたら、Issueの作成やPull Requestを通じて、ぜひお力をお貸しください。詳細は[CONTRIBUTING.md](README/CONTRIBUTING.md)をご覧ください。
