# MoneyKeeper

## 概要

### お金を前に差し出すのを辞めよう

企業によって積極的な (forward) 消費を促されることの多い現代社会にうんざりしていませんか？

本当に便利な世の中になったのでしょうか？

ポイントは本当にお得なんでしょうか？

QR コード決済は本当に便利なんでしょうか？

企業による過激なユーザーの囲い込み合戦に巻き込まれ、数多の情報や広告に踊らされるのにうんざりしたボクは、まずは真に必要な情報だけを表示するための家計簿を欲していました

### 本当の使いやすさを目指して

各銀行口座やキャッシュレス決済事業者などは、API をクローズドにし、営利目的のために独占していますので、自動取得をすることは難しいです。しかし、手動で入力する前提であれば、自作することは可能だと考えました

また、MoneyF……某有名家計簿アプリからの CSV をインポートする機能を備えれば、自動連携したデータを手動で持ってくることも可能になるはずです

お金の情報管理を自由に、オープンにすることが、MoneyKeeper の最終的な目標です。自分たちのお金は自分たちのものです。その情報をどのように扱うべきかは、自分たちで決定する権利があるはずです

もしこの考えに共感いただけるのであれば、ぜひあなたのアイデアを教えて下さい。MoneyKeeper が、あなたのお財布の番人 (Keeper) となれれば幸いです
